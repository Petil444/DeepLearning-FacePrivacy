# DeepLearning-FacePrivacy

딥러닝 기반 실시간 얼굴인식 정보 보호 시스템

## Features
- Real-time Face Recognition
- HOG Face Detection
- CNN-based ResNet Face Encoding
- FAISS Vector Search
- Privacy Protection System
- Unknown User Blur Processing

## Environment
- Python
- OpenCV
- Face Recognition
- FAISS
- NumPy
